## Overview  
Managing thoughts and tasks efficiently is crucial for productivity. **Note Taker Easy Mode** provides users with a simple yet powerful way to **write, view, and manage notes**, making it easy to stay organized.  

## Features  
✅ **Landing page with a link to the notes page** 🔗  
✅ **Create, modify, and delete notes** ✍️  
✅ **Click on existing notes to view/edit them** 🔄  
✅ **Seamless note organization for better task tracking** 🗂️  

## Installation & Usage  
### 1️⃣ Clone the Repository  
```sh
git clone git@github.com:san1718/mc11-Note_Taker.git
cd mc11-Note_Taker
```

### 2️⃣ Install Dependencies  
```sh
npm install
```

### 3️⃣ Start the Application  
```sh
node server.js
```

### 4️⃣ Open the App in Your Browser  
```
http://localhost:3001
```

## Technologies Used  
- Frontend
    - **HTML/CSS** (structure and styling)  
- Backend
    - **Node.js** (JavaScript runtime environment)  
    - **Express.js** (Server-side framework)  
    - **UUID** (Generates unique IDs for notes)  
    - **File System (fs)** (Handles note storage)  

## Summary  
📝 **Note Taker Easy Mode** is a lightweight, efficient note-taking application designed for **small business owners, professionals, and anyone who needs to keep track of tasks**.
